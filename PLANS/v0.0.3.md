# v0.0.3 — Additional probes, CLI commands, and coverage progress

## Goal
Extend pulsar with more probe types and begin CLI commands/collections, while growing unit tests and coverage.

## In scope
- More probe implementations behind the probe interface.
- CLI commands for basic target/collection workflows.
- Tests for new probe logic and CLI handling where feasible.
- Coverage tooling improvements and reporting.

## Out of scope
- Full GUI.
- Complete 100% coverage.
- Full signed multi-platform release automation.

## Acceptance
- New probes build and are testable.
- CLI supports basic commands.
- Tests run in CI-friendly way.
- Coverage report is available for core code.

## Notes
- Probes that require real network access will be covered by harness/mock tests where possible and by Linux integration later.
- This release is about expanding the surface that can be tested.
