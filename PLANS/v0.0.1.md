# v0.0.1 — Baseline CLI + portable build + first release

## Goal
Make pulsar buildable and distributable as a tiny native C CLI on Linux first, with a Nix build path that also supports macOS and Windows later, and ship the first GitHub Release.

## In scope
- CLI entrypoint with `--version` and a few safe no-op commands.
- Portable C core skeleton, no GUI yet.
- Nix build for Linux; structure for macOS/Windows.
- Signed build pipeline ready (unsigned first, signing integration next).
- GitHub Actions workflow that can build and release.
- First GitHub Release from the repo.

## Out of scope
- Real probes with network I/O.
- GUI.
- 100% coverage.
- Full multi-platform signed releases.

## Acceptance
- `nix build` produces a pulsar binary.
- Binary runs and reports its version.
- GitHub Actions can build the project.
- A GitHub Release exists for v0.0.1.

## Notes
- Signed builds are desired; we will prepare the pipeline now and integrate signing material later.
- Super-static Linux binary is a key future target; v0.0.1 will establish the build path toward that.
