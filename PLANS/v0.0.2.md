# v0.0.2 — Connectivity core: ICMP + DNS probes + unit tests

## Goal
Introduce a testable connectivity core for pulsar: target model, probe abstraction, ICMP ping and DNS probing, plus unit tests and the beginning of coverage work.

## In scope
- Core types: target, probe, measurement stats.
- Probe interface suitable for testing.
- ICMP probe support on Linux.
- DNS probe support on Linux.
- Unit tests for core logic: parsing, stats, probe control, serialization.
- Build and test runner in Nix.
- Coverage tooling hooked up.

## Out of scope
- Full probe catalog.
- CLI commands for collections.
- GUI.
- Complete 100% coverage.

## Acceptance
- Core library builds.
- Unit tests run and cover core logic.
- CI can build and test Linux.
- Probe code is separated from CLI/GUI concerns.

## Notes
- Real network probes are hard to test without harnesses; we will use controlled mocks and Linux-only integration where needed.
- This is the step where we start driving toward 100% coverage in a disciplined way.
